# 🧵 Fios & Artes — V4.29.2

Plataforma web de comércio e divulgação de produtos artesanais, com catálogo, autenticação, área do vendedor, gestão, estoque, imagens, notificações e integração com WhatsApp.

## V4.29.2

A versão 4.29.2 faz um ajuste pontual no sistema de ícones:

- O ícone de **Atendimento** em **Outras configurações** da Área do vendedor utiliza `comment`, igual ao ícone da navegação lateral.
- Nenhuma outra regra de negócio, layout, navegação, funcionalidade ou configuração do Supabase foi alterada nesta versão.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Supabase / PostgreSQL

## Estrutura mínima

```text
Fios-e-Artes/
├── index.html
└── README.md
```

O `index.html` concentra a aplicação e não depende de arquivos locais adicionais para ser executado.

## Supabase

O projeto utiliza Supabase para autenticação, banco de dados e recursos relacionados à aplicação. Não publique senhas, chaves privadas ou `service_role keys` no repositório.

## Publicação

O projeto pode ser hospedado em serviços compatíveis com sites estáticos, como GitHub Pages, desde que a configuração do Supabase esteja correta.
